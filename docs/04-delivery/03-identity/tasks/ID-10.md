## Тест-кейсы

### TC-ID-10-01: Rotation

- **Дано:** Старый ключ ещё валиден.
- **Действие:** Выпустить новым, проверить оба в overlap и после expiry.
- **Ожидается:** Новый работает, старый только в разрешённый срок.
- **Доказательство:** записать фактическое состояние/response/DB assertion или screenshot в test report. Для негативного сценария проверить также отсутствие запрещённого side effect.
- **Стартовый статус:** not-run.

### TC-ID-10-02: CSRF

- **Дано:** Auth cookie есть, Origin чужой/CSRF invalid.
- **Действие:** Выполнить mutation.
- **Ожидается:** Отказ без side effect.
- **Доказательство:** записать фактическое состояние/response/DB assertion или screenshot в test report. Для негативного сценария проверить также отсутствие запрещённого side effect.
- **Стартовый статус:** not-run.

### TC-ID-10-03: Token confusion

- **Дано:** Machine token на user endpoint и наоборот.
- **Действие:** Отправить запросы.
- **Ожидается:** Неверные aud/type отклонены.
- **Доказательство:** записать фактическое состояние/response/DB assertion или screenshot в test report. Для негативного сценария проверить также отсутствие запрещённого side effect.
- **Стартовый статус:** not-run.

### TC-ID-10-04: Revoke

- **Дано:** Valid access token, user suspended.
- **Действие:** Sensitive mutation.
- **Ожидается:** Отказ несмотря на неистёкший JWT.
- **Доказательство:** записать фактическое состояние/response/DB assertion или screenshot в test report. Для негативного сценария проверить также отсутствие запрещённого side effect.
- **Стартовый статус:** not-run.
