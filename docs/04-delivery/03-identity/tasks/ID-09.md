## Тест-кейсы

### TC-ID-09-01: Ownership

- **Дано:** User A видит свою session list.
- **Действие:** Подставить sessionId user B в request.
- **Ожидается:** Backend отказывает, данные B не показаны.
- **Доказательство:** записать фактическое состояние/response/DB assertion или screenshot в test report. Для негативного сценария проверить также отсутствие запрещённого side effect.
- **Стартовый статус:** not-run.

### TC-ID-09-02: Locale

- **Дано:** User явно выбирает RU.
- **Действие:** Reload и вход в другой сервис.
- **Ожидается:** Preference сохраняется; нет возврата на navigator default.
- **Доказательство:** записать фактическое состояние/response/DB assertion или screenshot в test report. Для негативного сценария проверить также отсутствие запрещённого side effect.
- **Стартовый статус:** not-run.

### TC-ID-09-03: Unavailable

- **Дано:** Auth API временно недоступен.
- **Действие:** Открыть кабинет.
- **Ожидается:** Понятный error/retry, не фиктивная пустая история.
- **Доказательство:** записать фактическое состояние/response/DB assertion или screenshot в test report. Для негативного сценария проверить также отсутствие запрещённого side effect.
- **Стартовый статус:** not-run.
