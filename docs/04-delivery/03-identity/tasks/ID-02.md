## Тест-кейсы

### TC-ID-02-01: Новый вход

- **Дано:** Проверенный provider subject.
- **Действие:** Пройти callback.
- **Ожидается:** Один user/identity, повтор callback не дублирует.
- **Доказательство:** записать фактическое состояние/response/DB assertion или screenshot в test report. Для негативного сценария проверить также отсутствие запрещённого side effect.
- **Стартовый статус:** not-run.

### TC-ID-02-02: Захват

- **Дано:** Provider email совпадает с другим user, владение не доказано.
- **Действие:** Попытаться link.
- **Ожидается:** Существующий account не присоединён автоматически.
- **Доказательство:** записать фактическое состояние/response/DB assertion или screenshot в test report. Для негативного сценария проверить также отсутствие запрещённого side effect.
- **Стартовый статус:** not-run.

### TC-ID-02-03: Unlink

- **Дано:** Единственный способ входа.
- **Действие:** Удалить identity.
- **Ожидается:** Отказ с понятным кодом; альтернативный verified способ позволяет unlink.
- **Доказательство:** записать фактическое состояние/response/DB assertion или screenshot в test report. Для негативного сценария проверить также отсутствие запрещённого side effect.
- **Стартовый статус:** not-run.
