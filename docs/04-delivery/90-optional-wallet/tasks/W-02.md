3. Внутренний API под сервисным токеном (`/v1/internal/debit`, `/credit-batch`, `/rollback`), API игрока (`/v1/me/wallet`, `/history`). **Контроль:** сохранить diff или артефакт шага и сверить с контрактом и TC ниже.

## Тест-кейсы

### TC-W-02-01: Одновременные списания

- **Дано:** Баланс 50, 100 одновременных списаний по 1 с разными ref на настоящем PostgreSQL.
- **Действие:** Отправить все запросы разом.
- **Ожидается:** Ровно 50 успешных, 50 ответов 402, баланс 0, в журнале 50 списаний, кэш равен журналу.
- **Доказательство:** имя теста и его вывод, состояние БД или скриншот в отчёте; для негативного сценария — отсутствие запрещённого эффекта.
- **Статус:** pass, [отчёт этапа 1](../../../09-evidence/wallet-phase1/report.md).

### TC-W-02-02: Повтор и конфликт ref

- **Дано:** Успешное списание с ref X.
- **Действие:** Повторить тот же запрос, затем ref X с другой суммой.
- **Ожидается:** Повтор — тот же ответ с `replayed: true` и без новой строки; другая сумма — 409 `IDEMPOTENCY_CONFLICT` (`ref: conflict`).
- **Доказательство:** имя теста и его вывод, состояние БД или скриншот в отчёте; для негативного сценария — отсутствие запрещённого эффекта.
- **Статус:** pass, [отчёт этапа 1](../../../09-evidence/wallet-phase1/report.md).

### TC-W-02-03: Надгробие

- **Дано:** Списания с ref Y ещё не было.
- **Действие:** Откатить Y, затем списать с ref Y; отдельно — откатить существующее списание дважды.
- **Ожидается:** Откат ставит надгробие, позднее списание — 409 (`ref: rolled_back`), баланс не изменился; существующее списание возвращается одной проводкой `reversal`, повтор отката — тот же ответ.
- **Доказательство:** имя теста и его вывод, состояние БД или скриншот в отчёте; для негативного сценария — отсутствие запрещённого эффекта.
- **Статус:** pass, [отчёт этапа 1](../../../09-evidence/wallet-phase1/report.md).

### TC-W-02-04: Пачка — всё или ничего

- **Дано:** Пачка из нескольких строк, одна с ref, уже использованным с другой суммой.
- **Действие:** Отправить пачку, затем исправленную пачку дважды.
- **Ожидается:** Первая пачка — 409 и ни одной записи; исправленная — все строки; повтор — те же операции с `replayed: true`.
- **Доказательство:** имя теста и его вывод, состояние БД или скриншот в отчёте; для негативного сценария — отсутствие запрещённого эффекта.
- **Статус:** pass, [отчёт этапа 1](../../../09-evidence/wallet-phase1/report.md).

### TC-W-02-05: Доступ

- **Дано:** Пользователи A и B, внутренний API.
- **Действие:** Без токена и с неверным токеном вызвать внутренний API; A читает свой кошелёк и историю.
- **Ожидается:** Внутренний API — 401; игрок видит только свой кошелёк и не видит причин, ref и meta.
- **Доказательство:** имя теста и его вывод, состояние БД или скриншот в отчёте; для негативного сценария — отсутствие запрещённого эффекта.
- **Статус:** pass, [отчёт этапа 1](../../../09-evidence/wallet-phase1/report.md).
