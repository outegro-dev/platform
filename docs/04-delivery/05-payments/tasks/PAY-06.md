## Тест-кейсы

### TC-PAY-06-01: Источники

- **Дано:** Purchase и manual grant одного feature.
- **Действие:** Отозвать purchase grant.
- **Ожидается:** Manual source остаётся active.
- **Доказательство:** записать фактическое состояние/response/DB assertion или screenshot в test report. Для негативного сценария проверить также отсутствие запрещённого side effect.
- **Стартовый статус:** not-run.

### TC-PAY-06-02: Idempotency

- **Дано:** Один payment event повторяется.
- **Действие:** Create grant повторно.
- **Ожидается:** Один grant на source+feature, срок не растёт.
- **Доказательство:** записать фактическое состояние/response/DB assertion или screenshot в test report. Для негативного сценария проверить также отсутствие запрещённого side effect.
- **Стартовый статус:** not-run.

### TC-PAY-06-03: Ordering

- **Дано:** Grant active v1 затем revoked v2.
- **Действие:** Replay v1 на authoritative command.
- **Ожидается:** v2 сохраняется, событие не откатывает state.
- **Доказательство:** записать фактическое состояние/response/DB assertion или screenshot в test report. Для негативного сценария проверить также отсутствие запрещённого side effect.
- **Стартовый статус:** not-run.
