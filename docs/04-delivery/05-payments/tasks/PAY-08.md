### C2. Реализовать ограниченный результат

1. Создать authenticated owner cancel command с idempotency и reason. **Контроль:** сохранить конкретный diff/артефакт этого шага; сверить с контрактом и связанными TC ниже перед переходом дальше.
2. Записать cancel_requested до provider вызова и отразить pending в UI model. **Контроль:** сохранить конкретный diff/артефакт этого шага; сверить с контрактом и связанными TC ниже перед переходом дальше.
3. Подтвердить cancelling по достоверному ответу/status и сохранить paidUntil. **Контроль:** сохранить конкретный diff/артефакт этого шага; сверить с контрактом и связанными TC ниже перед переходом дальше.
4. Timeout оставить проверяемым через reconcile, не показывать ложный success. **Контроль:** сохранить конкретный diff/артефакт этого шага; сверить с контрактом и связанными TC ниже перед переходом дальше.
