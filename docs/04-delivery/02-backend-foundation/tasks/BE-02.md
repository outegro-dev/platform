## Тест-кейсы

### TC-BE-02-01: Confirm

- **Дано:** Broker доступен и очередь привязана.
- **Действие:** Publish с confirm.
- **Ожидается:** Caller получает подтверждение; nack/error не отмечается как успех.
- **Доказательство:** записать фактическое состояние/response/DB assertion или screenshot в test report. Для негативного сценария проверить также отсутствие запрещённого side effect.
- **Стартовый статус:** not-run.

### TC-BE-02-02: Reconnect

- **Дано:** Worker потребляет сообщение.
- **Действие:** Остановить/восстановить тестовый broker.
- **Ожидается:** Connection восстановлен, unacked message доступен заново.
- **Доказательство:** записать фактическое состояние/response/DB assertion или screenshot в test report. Для негативного сценария проверить также отсутствие запрещённого side effect.
- **Стартовый статус:** not-run.

### TC-BE-02-03: Shutdown

- **Дано:** Есть in-flight handler.
- **Действие:** Послать termination.
- **Ожидается:** Новые messages не берутся, незавершённое не теряется.
- **Доказательство:** записать фактическое состояние/response/DB assertion или screenshot в test report. Для негативного сценария проверить также отсутствие запрещённого side effect.
- **Стартовый статус:** not-run.
