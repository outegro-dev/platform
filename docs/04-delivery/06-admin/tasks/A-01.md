## Тест-кейсы

### TC-A-01-01: Anonymous

- **Дано:** Нет сессии.
- **Действие:** Открыть admin route/API.
- **Ожидается:** Login/401 без private response.
- **Доказательство:** записать фактическое состояние/response/DB assertion или screenshot в test report. Для негативного сценария проверить также отсутствие запрещённого side effect.
- **Стартовый статус:** not-run.

### TC-A-01-02: Обычный user

- **Дано:** Valid user session без permission.
- **Действие:** Вызвать admin API напрямую.
- **Ожидается:** 403 независимо от скрытой кнопки.
- **Доказательство:** записать фактическое состояние/response/DB assertion или screenshot в test report. Для негативного сценария проверить также отсутствие запрещённого side effect.
- **Стартовый статус:** not-run.

### TC-A-01-03: Actor spoof

- **Дано:** Operator передаёт actorId владельца.
- **Действие:** Выполнить command.
- **Ожидается:** Actor определяется session/delegation, подмена отклонена.
- **Доказательство:** записать фактическое состояние/response/DB assertion или screenshot в test report. Для негативного сценария проверить также отсутствие запрещённого side effect.
- **Стартовый статус:** not-run.
