- **Дано:** Один owner.
- **Действие:** Снять роль из admin.
- **Ожидается:** Domain backend отказывает, UI показывает причину.
- **Доказательство:** записать фактическое состояние/response/DB assertion или screenshot в test report. Для негативного сценария проверить также отсутствие запрещённого side effect.

- **Дано:** Два оператора редактируют flag v1.
- **Действие:** Сохранить оба.
- **Ожидается:** Один update, второй conflict с refresh.
- **Доказательство:** записать фактическое состояние/response/DB assertion или screenshot в test report. Для негативного сценария проверить также отсутствие запрещённого side effect.

- **Действие:** Создать checkout и принять старый webhook.
- **Ожидается:** Новый checkout запрещён, webhook всё ещё принимается.
