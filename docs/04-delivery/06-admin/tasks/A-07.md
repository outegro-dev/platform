## Тест-кейсы

### TC-A-07-01: Atomicity

- **Дано:** Domain mutation, audit write failure.
- **Действие:** Выполнить command.
- **Ожидается:** Либо оба commit, либо mutation не выполнена.
- **Доказательство:** записать фактическое состояние/response/DB assertion или screenshot в test report. Для негативного сценария проверить также отсутствие запрещённого side effect.
- **Стартовый статус:** not-run.

### TC-A-07-02: Projection down

- **Дано:** Central admin projection недоступна.
- **Действие:** Выполнить разрешённую mutation.
- **Ожидается:** Domain audit не потерян и приходит после восстановления.
- **Доказательство:** записать фактическое состояние/response/DB assertion или screenshot в test report. Для негативного сценария проверить также отсутствие запрещённого side effect.
- **Стартовый статус:** not-run.

### TC-A-07-03: Redaction

- **Дано:** Секретоподобный input/HTML note.
- **Действие:** Просмотреть audit.
- **Ожидается:** Нет tokens/raw credentials и исполняемого HTML.
- **Доказательство:** записать фактическое состояние/response/DB assertion или screenshot в test report. Для негативного сценария проверить также отсутствие запрещённого side effect.
- **Стартовый статус:** not-run.

### TC-A-07-04: Denied

- **Дано:** Auditor вызывает revoke/refund.
- **Действие:** Отправить напрямую.
- **Ожидается:** Denied recorded как отказ, успешного side effect нет.
- **Доказательство:** записать фактическое состояние/response/DB assertion или screenshot в test report. Для негативного сценария проверить также отсутствие запрещённого side effect.
- **Стартовый статус:** not-run.
