## Тест-кейсы

### TC-H-08-01: Дубль

- **Дано:** Один Telegram update/message повторился после restart.
- **Действие:** Ingest дважды.
- **Ожидается:** Один source/item, media не дублируются логически.
- **Доказательство:** записать фактическое состояние/response/DB assertion или screenshot в test report. Для негативного сценария проверить также отсутствие запрещённого side effect.
- **Стартовый статус:** not-run.

### TC-H-08-02: Version

- **Дано:** Два edit одного item v1.
- **Действие:** Update одновременно.
- **Ожидается:** Один успех, второй version conflict.
- **Доказательство:** записать фактическое состояние/response/DB assertion или screenshot в test report. Для негативного сценария проверить также отсутствие запрещённого side effect.
- **Стартовый статус:** not-run.

### TC-H-08-03: Media

- **Дано:** Слишком большой или запрещённый файл.
- **Действие:** Ingest.
- **Ожидается:** Controlled reject, нет исчерпания RAM/диска.
- **Доказательство:** записать фактическое состояние/response/DB assertion или screenshot в test report. Для негативного сценария проверить также отсутствие запрещённого side effect.
- **Стартовый статус:** not-run.

### TC-H-08-04: Чужие данные

- **Дано:** Credential assistant-store.
- **Действие:** Попытаться читать payments/users DB.
- **Ожидается:** Недоступно по role/network/tool contract.
- **Доказательство:** записать фактическое состояние/response/DB assertion или screenshot в test report. Для негативного сценария проверить также отсутствие запрещённого side effect.
- **Стартовый статус:** not-run.
