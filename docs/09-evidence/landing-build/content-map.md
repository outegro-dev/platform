# Карта первого лендинга

Основание — прямое поручение владельца самостоятельно реализовать дизайн и лендинг. Объединены необходимые части BOOT/L/DS; полный backend-план не выполнялся.

| Секция | Сообщение | Контент и действие |
|---|---|---|
| Hero | Full-stack с вниманием ко всем уровням | Nick Lukashik, роль, серебряная NL, переход к подходу |
| Expertise | Практическое применение технологий | UI/performance; backend/data; deployment/operations, accordion |
| Approach | Как принимаются решения | Системное мышление, пользователь, доставка |
| Projects | Здесь появятся собственные продукты | Честная заглушка, никаких фиктивных кейсов |
| Contact | Приглашение к сотрудничеству | Диалог с configured-empty состоянием; будущие email/Telegram/LinkedIn |

Основные словари: `apps/landing-web/src/messages/en.json`, `ru.json`. Публичные контакты: `apps/landing-web/src/lib/contact.ts`, значения build-time env. Адреса валидируются; неизвестные/неподходящие URL не становятся ссылками.

Не включены: личные здоровье/питание/документы, outegro.com, выдуманные клиенты, testimonials, awards, публичный Battleship до его реализации. Контактная форма не имитирует отправку сообщения.

Повторное использование старого проекта: подход pnpm/Turbo/Biome, Next App Router, next-intl и совместимый frontend-стек. Исходники backend, Prisma, env, production данные, секреты и инфраструктурные manifests не копировались. Landing/UI написаны заново под новый brief. Инфраструктура остаётся отдельным следующим этапом.
