# Передача TASK-ID

1. Цель задачи одним предложением.
2. Прочитанные контракты и принятые решения.
3. Завершённые шаги со ссылками на diff/evidence.
4. Последний реальный test result, что не запускалось.
5. Незавершённый шаг и его конкретный следующий action.
6. Точные файлы, которые нужно открыть следующей модели.
7. Необходимый input/внешний blocker, если есть.
8. Несвязанные пользовательские изменения, которые нельзя перезаписывать.

Не пересказывать всю историю проекта. Не записывать «всё готово», если остались обязательные tests.
