# Маршрут чтения

Для владельца: [контекст](project-context.md), [карта этапов](../04-delivery/README.md), [открытые решения](../03-decisions/open-inputs.md). Полное предметное описание находится в [16 главах](../01-specification/README.md).

Для модели-исполнителя:

1. Прочитать корневой [AGENTS.md](../../AGENTS.md).
2. Прочитать [контекст](project-context.md), [протокол](execution-protocol.md), [карту репозитория](repository-map.md).
3. Найти конкретную карточку через [индекс задач](../04-delivery/README.md) либо context helper.
4. Прочитать только перечисленные в ней контракты и главы. Полный 130k+ документ не нужно держать в контексте каждого задания.
5. Проверить предусловия, выполнить один шаг, проверить результат, продолжить. Не переходить через незакрытый архитектурный выбор по догадке.
6. Сдать код и [отчёт](../07-templates/task-report.md). Для документационных задач артефакт — документ с фактами и решением, без выдуманного unit test.

Все task cards — задания на будущую реализацию. Test cases описывают ожидаемое поведение и ещё не являются исполненными тестами.

[Готовые поручения модели и возобновление задачи](prompts.md) позволяют начать с BOOT-01 или передать одну карточку другой модели без истории чата.
