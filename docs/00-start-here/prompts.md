## Разбор блокировки

```text
У TASK-ID заблокирован TC-ID. Определи точный missing input или противоречие.
Не обходи authorization/idempotency/денежные инварианты ради зелёного теста.
Заверши независимую часть, сохрани минимальный reproducer, предложи конкретный
вариант решения и укажи, какая другая planned задача сейчас ready.
```

Подробность карточки снижает объём догадок, но не гарантирует качество любой модели. Для сложного security/protocol/provider решения нужен доказанный spike и review, особенно если модель предлагает новый алгоритм вместо поддерживаемой библиотеки.
